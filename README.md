# JMG — projet React organisé par pages

## Lancer le projet
1. Décompresse `JMG-Bank-App.zip`.
2. Ouvre le dossier `JMG-Bank-App` dans VS Code.
3. Dans le terminal :
   ```bash
   npm install
   npm run dev
   ```

## Accès de démonstration
- Code utilisateur : `JMG001`
- Mot de passe : `123456`

## Structure
- `src/pages/` : une page JSX par écran.
- `src/components/` : éléments réutilisables.
- `src/context/AuthContext.jsx` : session locale.
- `src/services/UserService.js` : utilisateur de démonstration.
- `public/images/L1.jpeg` : logo JMG.

Les données financières et opérations sont des exemples. Aucun compte bancaire n'est connecté, aucun paiement ou virement réel n'est exécuté. Le projet ne représente pas ING.
